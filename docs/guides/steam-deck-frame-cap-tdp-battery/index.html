Steam Deck: frame cap, TDP and battery basics

By the Patch Play Guide editorial team, AdStern

Reviewed November 2, 20264 min readHow we check pages

The Steam Deck gives you more control than any console: a performance menu with frame limit, refresh rate, power limit and scaling options, saved per game if you want. Used together, they turn a game that swings between 35 and 55 frames per second and empties the battery in 90 minutes into one that runs evenly and lasts much longer. This guide explains each option and a simple order to set them.

Where the settings are

Press the … (Quick Access) button and open the Performance tab (the battery icon). There you find the performance overlay level, the frame-rate limit, the refresh rate, an option to allow tearing, half-rate shading, a TDP limit, manual GPU clock control and the scaling filter. Turn on “Use per-game profile” to store these settings for the game you are playing instead of globally. Option names and layout can change with SteamOS updates.

Frame cap first

An uncapped game on the Steam Deck runs as fast as it can, so the frame rate swings with the scene and the APU uses its full power all the time. A cap that the game can hold almost everywhere gives you even frame pacing and leaves power unused – which saves battery and heat.

The 40 fps trick. Set the refresh rate to 40 Hz and cap at 40 fps. Each frame then takes 25 ms, exactly halfway between 30 fps (33.3 ms) and 60 fps (16.7 ms), and it fits the refresh rate evenly. Many games that cannot hold 60 run comfortably at 40, and it feels clearly smoother than 30. On the OLED model with its higher refresh range, 45 fps at 90 Hz is another even combination.

Resolution and upscaling

The Steam Deck screen is 1280×800. Many games run well at that resolution with medium settings; demanding ones need a lower internal resolution. If the game has its own upscaler – FSR, XeSS or an engine upscaler – use it with the output at 1280×800; at such a low output resolution, the Quality mode is usually the best compromise (see DLSS vs FSR vs XeSS). Alternatively, set the game to a lower resolution such as 960×600 and use the Steam Deck’s FSR scaling filter, which sharpens the upscaled image at the system level.

Textures can often stay at medium or high – the Steam Deck has 16 GB of shared memory – but the GPU is modest, so lighting, shadows and volumetrics are the effects to lower first.

TDP and battery

The TDP limit caps how much power the processor may use. With a frame cap in place, many games do not need the full budget; lowering the TDP limit until the frame rate starts to drop, then raising it a step, saves battery. Be careful: CPU and GPU share the budget, so a TDP that is too low makes both slower and can cause stutter in CPU-heavy moments.

  • Set the frame cap first, then lower the TDP while watching the overlay.
  • Screen brightness has a large effect on battery life – lower it indoors.
  • Use per-game profiles so a light game does not inherit the settings of a demanding one.
  • Check the Steam Deck Compatibility rating (Verified, Playable, Unsupported, Unknown) on the store page for known issues.

A simple order for any game

  1. Start with the game’s medium or “Steam Deck” preset if it has one.
  2. Turn on the performance overlay and play a demanding section.
  3. Choose a cap the game can hold nearly always: 30, 40 (with 40 Hz), 45 (OLED, 90 Hz) or 60.
  4. If it cannot hold the cap, lower render resolution or use an upscaler before lowering textures.
  5. Lower the TDP limit for battery if the frame rate stays stable.
  6. Save the per-game profile.

After a game update, check the profile is still active and expect some shader compilation – Steam’s Shader Pre-Caching helps here, see shader stutter after an update.

Frequently asked questions

What is the best frame cap on Steam Deck?

The highest one your game holds nearly all the time. 40 fps at 40 Hz is a popular middle ground for demanding games; lighter games can run at 60.

Does lowering TDP improve battery life?

Yes, if the game still holds its frame cap. Lower it gradually while watching the overlay; too low a limit causes drops and stutter.

Should I use the FSR scaling filter?

It is useful when a game renders below 1280×800 and has no good built-in upscaler. If the game offers its own upscaler, that one is usually better.

What does half rate shading do?

It reduces shading work in parts of the image in supported games. It saves GPU time at the cost of some sharpness.
