Frame caps, V-Sync and latency on PC explained

Published by AdStern, Vienna

Reviewed November 3, 20264 min readHow we check pages

Tearing, judder and laggy controls come from how frames are handed to the display. V-Sync, frame caps, variable refresh rate and latency-reduction modes each solve one part of the problem – and some combinations cancel each other out. This guide explains each tool and a setup that works for most PC players with a VRR monitor.

The problem: a game and a display on different clocks

A display refreshes at a fixed rate – 60, 144, 165 Hz or more – unless it supports variable refresh rate. A game produces frames whenever they are ready. If a new frame is sent to the display in the middle of a refresh, the top part of the screen shows the old frame and the bottom the new one: a tear. If the game waits for the next refresh instead, there is no tearing, but frames can wait, and when the game cannot keep up, some frames are shown twice – judder – while the waiting adds latency.

The tools

ToolWhat it doesBenefitDownside
V-SyncWaits for the display refresh before showing a frameNo tearingAdded latency; judder when below refresh rate
VRR (G-Sync, FreeSync, HDMI VRR)The display refreshes when a frame is readyNo tearing, smooth at fluctuating FPSOnly within the display’s range
Frame cap (limiter)Limits FPS to a set valueEven frame pacing, stays within VRR range, less heatLeaves performance unused
Latency reduction (NVIDIA Reflex, AMD Anti-Lag 2, Intel XeLL)Keeps the CPU from running ahead of the GPULower input latency when GPU-boundNeeds game support for in-game versions
Triple buffering / fast sync modesVariants of buffering between game and displayLess judder or tearingBehavior differs by implementation

Latency reduction matters most when the GPU is fully loaded: then the CPU tends to prepare frames ahead, they queue up, and every queued frame adds delay between your input and the screen. Reflex and Anti-Lag 2 are integrated into games; driver-level options exist as well but are generally less precise.

A setup that works for most people

If you have a VRR monitor (G-Sync or FreeSync compatible), a widely recommended setup is:

  1. Enable VRR (G-Sync / FreeSync) in the GPU driver and, if necessary, in the monitor’s menu.
  2. Cap the frame rate a few frames below the refresh rate – for example around 141 fps on a 144 Hz display – so the game stays inside the VRR range instead of hitting V-Sync behavior at the top. Some latency-reduction modes apply such a cap automatically.
  3. Enable the game’s latency-reduction option (Reflex, Anti-Lag 2) if available.
  4. Many guides also recommend enabling V-Sync in the driver together with VRR, to avoid tearing at the top of the range; follow your GPU vendor’s current recommendation.

Without a VRR display

Without VRR you have to choose. V-Sync on gives a tear-free image; it works best when the game can hold the full refresh rate at all times, otherwise judder appears. A cap at exactly the refresh rate, or at half of it (30 fps on 60 Hz), keeps frame pacing even. V-Sync off gives the lowest latency with visible tearing; competitive players often accept this, usually with a high uncapped or capped frame rate well above the refresh rate.

Why a frame cap helps even without latency concerns

A cap that your PC can hold nearly all the time turns a frame rate that swings between 95 and 130 into a steady 90 – with even frame times, which often feels smoother than the higher but uneven rate. It also lowers power use, heat and fan noise, which matters on laptops and handheld PCs. In-game limiters are generally preferred over external ones because they can pace frames inside the game’s own loop, but driver and overlay limiters (for example in the NVIDIA App, AMD Software or RivaTuner Statistics Server) are good alternatives when a game has no limiter. A cap only removes the peaks: if a scene drops below the cap – say to 70 fps – it stays at 70, so pick a cap below your usual lows.

With frame generation

Frame generation changes the picture: displayed frames are partly generated, and latency follows the rendered frames. Games that support it usually force the matching latency-reduction mode. Keep the output frame rate inside the VRR range and follow the vendor’s guidance for V-Sync and caps with frame generation – see frame generation explained.

Checking the result

Watch a frame-time graph rather than the FPS number. A flat line means even pacing; spikes mean stutter that no V-Sync setting will fix – see FPS, frame time and 1% lows. Then judge the feel: quick camera turns in the same scene with each setup. If the controls feel delayed although the frame rate is high, the Bottleneck Finder has a branch for latency.

Frequently asked questions

Should I turn V-Sync on or off?

With a VRR monitor, many players use VRR plus a frame cap a few frames below the refresh rate, often with V-Sync enabled in the driver. Without VRR, V-Sync on prevents tearing but adds latency; off gives the lowest latency with tearing.

What frame cap should I use with G-Sync or FreeSync?

A few frames below the maximum refresh rate, for example about 141 fps on a 144 Hz display, so the game stays within the VRR range.

What does NVIDIA Reflex do?

It reduces the queue of frames waiting for the GPU, so your input reaches the screen sooner. It helps most when the GPU is fully loaded.

Does a frame cap reduce input lag?

It can, when it keeps the GPU from running at full load and stops frames from queuing. A cap far below what your PC can do adds a little delay per frame, though.
