CPU or GPU bottleneck? A 5-minute check

By the Patch Play Guide editorial team, AdStern

Reviewed November 2, 20264 min readHow we check pages

Every system has a bottleneck – the part that is busiest while the others wait. Knowing which one it is decides which settings help. The good news: you do not need benchmarks or special knowledge. One resolution test and a glance at GPU usage answer the question for the game you are playing right now.

What a bottleneck is

For each frame, the CPU prepares the work – game logic, physics, animation, the list of objects to draw – and the GPU draws it. The two work in parallel on consecutive frames, so the frame rate is set by whichever takes longer per frame. If the CPU needs 12 milliseconds and the GPU 14, the GPU is the bottleneck and the game runs at about 71 frames per second (1000 ÷ 14). Speeding up the CPU’s part changes nothing.

The bottleneck is not a property of your PC alone. It depends on the game, the scene, the settings and the resolution. The same PC can be GPU-bound in a forest at 4K and CPU-bound in a crowded city at 1080p. That is why the check below is done in the game and place where you have the problem.

The 5-minute check

  1. Pick a spot. Go to a demanding place where the frame rate is low, and stand still or repeat the same short movement.
  2. Note the frame rate. Use the game’s counter or an overlay. Wait a few seconds for it to settle.
  3. Lower the render resolution sharply. Set the upscaler to Performance, or the render scale to about 50%. Do not change anything else.
  4. Compare. If the frame rate rises clearly – roughly by a quarter or more – the GPU was the limit. If it barely moves, something else limits you.
  5. Confirm with GPU usage. In an overlay, a GPU near 95–100% load points to a GPU limit. Clearly lower usage while the frame rate is low points to the CPU or a frame limiter.
  6. Restore your settings. The test was a diagnosis, not a recommendation.

If you are GPU-bound

This is the easier case, because graphics settings work directly. In order of value:

  • Use an upscaler and step its mode down (Quality → Balanced) – see DLSS vs FSR vs XeSS.
  • Lower ray tracing quality or turn off individual ray-traced effects.
  • Drop volumetric fog, shadows and ambient occlusion one step from maximum.
  • Keep textures high if your VRAM allows – they cost little GPU time.

Being GPU-bound is normal and not a problem in itself; most games at high settings are. It only matters when the frame rate is lower than you want.

If you are CPU-bound

Resolution and most effects will not help, so you can keep image quality high. What helps is less work per frame for the processor:

  • Lower view distance or level of detail, crowd and traffic density, and physics or destruction detail.
  • Close background programs that use the CPU heavily: browsers with video, recording, downloads.
  • Check that the game runs from an SSD; streaming from a slow drive adds CPU waiting time.
  • Consider a frame cap a little below your average to make frame times more even.
  • Check patch notes: CPU-related optimizations (for example in crowded areas) are common in updates.

When neither seems to be the limit

If the GPU is not fully used and lowering resolution does nothing, check for a frame limiter first: an in-game cap, V-Sync, a driver limit, or a laptop or handheld power mode. These hold the frame rate down while both CPU and GPU have time to spare – nothing is “too slow”. Laptops on battery and hot systems can also throttle clocks. And if video memory is full, stutter and blurry textures appear regardless of CPU or GPU load, see VRAM full.

Why the bottleneck moves within one game

A game is not one workload. An empty desert at sunset with volumetric fog stresses the GPU; a market full of characters stresses the CPU; a cutscene with close-up faces may stress neither. That is why the check should be done where your problem is, and why one setting rarely fixes everything. Many players end up with a combination: an upscaler mode chosen for GPU-heavy areas and a lower crowd density for the busiest hub.

Patches can move the bottleneck too. An update that optimizes crowd simulation can turn a CPU-bound city into a GPU-bound one, and suddenly resolution matters there. After a big update, repeat the five-minute check in your problem area before changing settings – it takes less time than reading a long forum thread.

Frequently asked questions

Is a CPU bottleneck bad?

Not necessarily. Every system has a bottleneck. It only matters if the frame rate it allows is lower than you want.

Why does my GPU never reach 100%?

Usually because the CPU or a frame limiter (cap, V-Sync, power mode) holds the frame rate down. Some games also report lower usage even when GPU-bound.

Does a higher resolution reduce CPU bottlenecks?

It shifts more load to the GPU, so the GPU may become the limit, but the frame rate does not go up. It can, however, give you better image quality for free when you are CPU-bound.

Which tools show GPU usage?

The overlays in GPU driver software, the Steam overlay performance monitor, the Steam Deck performance overlay and tools such as PresentMon.
